# Neural Network Practical 🧠

This repository contains practical implementations, lab exercises, and experiments with Neural Networks. It demonstrates fundamental deep learning concepts, from building basic perceptrons to training multi-layer architectures.

## 🧪 List of Practicals

Here is the list of practical experiments included in this repository:

1. **Practical 1: Logic Gates using Perceptron**
   * Implementation of AND, OR, and NOT gates using a Single Layer Perceptron.
2. **Practical 2: Solving the XOR Problem**
   * Implementation of the XOR gate using a Multi-Layer Perceptron (MLP) and backpropagation.
3. **Practical 3: Activation Functions Analysis**
   * Implementing and visualizing different activation functions (Sigmoid, ReLU, Tanh, Softmax).
4. **Practical 4: Handwritten Digit Classification**
   * Building a Feedforward Neural Network to classify handwritten digits from the MNIST dataset.
5. **Practical 5: Image Classification with CNNs**
   * Designing a Convolutional Neural Network (CNN) for image classification (e.g., using CIFAR-10).
6. **Practical 6: Time Series Forecasting**
   * Using a Recurrent Neural Network (RNN) or Long Short-Term Memory (LSTM) network to predict sequential data.
7. **Practical 7: Hyperparameter Tuning & Optimization**
   * Experimenting with different optimizers (SGD, Adam) and tuning learning rates to observe their effect on model convergence.
